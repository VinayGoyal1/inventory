# Inventory Management System

This is an inventory management project I built in Python.

I didn't build the final version all at once. I started with a basic version that stored the inventory using a JSON file. After getting the first version working, I copied it and added new features step by step.

### Versions

**1. Basic JSON version**

I first created a simple inventory system that used JSON to store the inventory data. This helped me understand how to save and load data from a file instead of losing everything when the program stopped.

**2. JSON + Logging**

After the basic version worked, I duplicated it and added Python's `logging` module.

This version keeps track of important events and errors while the program is running. It made the project feel more like an actual application instead of just a practice program.

**3. JSON + Logging + CSV**

For the third version, I duplicated the logging version and added CSV functionality.

The inventory can now also be exported to a CSV file, which makes the data easier to open and view in spreadsheet programs.

### What I used

* Python
* JSON
* CSV
* Logging

### What I learned

The main thing I wanted to learn from this project was how to take a basic Python program and keep improving it by adding features.

I practiced working with JSON and CSV files, logging events and errors, and organizing the code as the project became bigger.

The three versions show how the project developed from a basic JSON-based program into a more complete inventory system.
